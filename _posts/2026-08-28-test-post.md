I've decided to add a small blog to this site. I expect this to be a place for
occasional notes about research, mathematics, neuroscience, machine learning,
and other things that seem useful to write down.

One motivation is that there are often ideas that are too small or preliminary
for a paper, but that become much clearer once I try to explain them carefully.

## Equations

The blog supports LaTeX. For example, suppose two neural representations are
matrices

$$
X, Y \in \mathbb{R}^{n \times d}.
$$

A simple way to compare them after allowing an orthogonal change of basis is the
Procrustes problem

$$
\min_{R^T R = I} \|X - YR\|_F^2.
$$

Inline equations work too, such as $$R^T R = I$$.

## Code

Markdown code blocks work as well:

```python
import numpy as np

X = np.random.randn(100, 20)
Y = np.random.randn(100, 20)

print(X.shape, Y.shape)
```

## Links and images

Links use ordinary Markdown. For example, here is my
[GitHub profile](https://github.com/SarahHarvey).

Images can be stored anywhere in the repository and included with ordinary
Markdown:

```markdown
![Description of image](/path/to/image.png)
```

That's enough machinery for now.
